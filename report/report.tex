\begin{abstract}
\vspace{2em}
\begin{minipage}{0.50\linewidth}
\vspace{-2em}
The problem that we are trying to solve is that of rendering the Mandelbrot set, a
famous fractal pattern produced by iterating the complex quadratic recurrence relation:
\begin{equation}
    Z_{n+1} = Z_{n}^{2} + C
\end{equation}

where $Z_{n}$ is the value of the iteration after $n$ iterations, and $C$ is a complex
number representing a point in the complex plane. The value of $Z_{0}$ is usually taken
to be zero. The iteration is repeated until the magnitude of $Z_{n}$ exceeds $2$ (at
which point the sequence diverges), or a maximum number of iterations is reached (at
which point the point is considered to be part of the Mandelbrot set). The iteration
count is then used to assign a colour to the pixel representing that point, thus
rendering the set.
\end{minipage}

\end{abstract}
