\begin{abstract}
\vspace{2em}
\begin{minipage}{1.0\linewidth}
\vspace{-2em}
The Mandelbrot set is a famous fractal pattern produced by iterating the complex quadratic recurrence relation:
\begin{equation}\label{eq:set}
    Z_{n+1} = Z_{n}^{2} + C
\end{equation}
where $Z_{n}$ denotes the complex value after $n$ iterations, and $C$ 
denotes a point on the complex plane. After $n = N$ iterations, where $N$ is 
defined as an upper-bound for number of iterations, points which 
have not diverged form the Mandelbrot set.

It can be assumed that points which exceed the complex-plane origin 
by a radius of $2$ will eventually diverge, yielding the 
following axiom for computing the Mandelbrot set $M$:
\begin{equation}\label{eq:axiom}
    \mathbb{M} = \{\;c \in \mathbb{C},\;\sup_{n \in \mathbb{N}} |Z_{n}| \leq 2,\;\text{where}\;Z_{0}=0\;\text{and}\;Z_{n+1}=Z_{n}^{2}+c\;\}
\end{equation}

. Points of the Mandelbrot set will inevitably  $N$ 

It can be shown that values of $Z_{n}$ which exceed $2$ will diverge, as such 
The value of $Z_{0}$ is usually taken to be zero. The iteration is repeated until the magnitude of $Z_{n}$ ($|Z_{n}|$) exceeds $2$ (at which point the sequence diverges), or a maximum number of iterations is reached (at
which point the point is considered to be part of the Mandelbrot set). The iteration
count is then used to assign a colour to the pixel representing that point, thus
rendering the set.

\subsection{Initial Implementation using Complex Float (serial\_0)}

\begin{lstlisting}[caption={Complex Float Algorithm}]
k = 1;
while ((cabsf(z) <= 2.0f) && (k++ < MAXITER)) 
    z = z * z + kappa;  
\end{lstlisting}

\subsection{Replacing Complex Float with Parametric Primitives (serial\_1)}

\begin{lstlisting}[caption={Parametric Form Algorithm}]
k = 1;
while (((zi * zi) + (zj * zj) <= 4.0f) && (k++ < MAXITER)) { 
    new_zi = (zi * zi) - (zj * zj) + ki;
    zj = 2.0f * zi * zj + kj;
    zi = new_zi;
}
\end{lstlisting}

As shown by Table~\ref{tab:serial_gprof}, 87.5\% of \texttt{serial\_0}'s execution 
time is spent on line 29, which contains the \texttt{cabsf(z)} call to compute:

\begin{equation*}
    |z| = \sqrt{z_r^2 + z_i^2}
\end{equation*}

The \texttt{sqrtf()} operation is computationally expensive, requiring either 
iterative approximation or specialised hardware instructions with high 
latency. Additionally, \texttt{serial\_0}'s low IPC of $0.95$ in 
Table~\ref{tab:serial_perf} suggests the CPU pipeline is frequently stalled 
on \texttt{sqrt()}, preventing effective instruction-level parallelism.

As such, \texttt{serial\_1} uses the equivalent comparison 
\[z_r^2 + z_i^2 \leq 4.0\] to avoid the square root entirely.


\subsection{Mirroring about the real-axis}

only one half must be iterated; the other half can simply mirror the results. This
